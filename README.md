# Мой Силант

Дипломный проект курса SkillFactory «Fullstack-разработчик на Python».

Веб-сервис представляет электронную сервисную книжку техники «Силант».

## Возможности

- публичный поиск машины по заводскому номеру;
- разграничение доступа по ролям;
- просмотр данных о машинах, техническом обслуживании и рекламациях;
- добавление и изменение данных в соответствии с правами пользователя;
- управление справочниками менеджером;
- создание пользователей и управление паролями через Django Admin;
- фильтрация и сортировка данных;
- адаптивный интерфейс.

## Роли

В проекте используются следующие роли:

- клиент;
- сервисная организация;
- менеджер;
- администратор Django.

Один пользователь может одновременно принадлежать к группам клиента и сервисной организации.

Самостоятельная регистрация пользователей, смена и восстановление пароля отключены. Учётные записи создаются администратором.

## Запуск проекта

Создать и активировать виртуальное окружение:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Установить зависимости:

```powershell
pip install -r requirements.txt
```

Применить миграции:

```powershell
python manage.py migrate
```

Запустить сервер:

```powershell
python manage.py runserver
```

После запуска приложение доступно по адресу:

```text
http://127.0.0.1:8000/
```

## Демонстрационные данные

В репозитории находится демонстрационная база `db.sqlite3` с исходными данными проекта.

Данные для входа в демонстрационные учётные записи передаются отдельно и не хранятся в публичном репозитории.

## Тесты

Запуск автоматических тестов:

```powershell

```
